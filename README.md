# شبكة تمريضيون التعليمية — Nursing's Educational Network

Bilingual (English/Arabic) study website with NCLEX-style quizzes for the unified syllabus of the Iraqi nursing colleges' evaluation exam (الامتحان التقويمي) — theoretical and practical.

Subjects: Adult Nursing · Microbiology for Nurses · Pediatric Nursing · Maternity & Neonatal Nursing · Community Health Nursing · Psychiatric Mental Health Nursing.

- Static site (no build tools needed to view) — hosted on GitHub Pages.
- Content lives in `data/<subject>/<topic>.js`. After editing, `node tools/build.js` validates the files and refreshes `data/manifest.js`.
